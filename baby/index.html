🧭 콘텐츠 축 비중목표 vs 실제

재우기가 가장 큰 비중 — 초보 부모 검색량 1위이자 저장·공유가 가장 잘 터지고, 보아르 확장 카테고리(수면등·가습기)와 맞물립니다.
출산준비는 비중은 작아도 구매 직전 고객이 모이는 축입니다. 이 구간에서 잡은 팔로워가 실제 매출로 전환됩니다.

📅 발행 캘린더

주 5회 발행 슬롯. 팔로워 성장 구간에서는 빈도가 곧 성장 속도입니다.

⚙️ 발행 설정

육아 계정은 밤 20:00~22:00이 가장 강합니다. 아이 재우고 난 뒤 부모가 폰을 드는 시간입니다.

🗓 예정 슬롯앞으로 4주

✨ 소재

민채님이 주제를 던지면 여기에 쌓입니다. 축·시기를 붙여두면 캘린더 배정과 제작이 자동으로 이어집니다. 범위는 임신 막달 ~ 36개월.

➕ 주제 던지기

타깃은 임신 막달(출산준비) ~ 36개월입니다. 출산준비기가 육아템을 한 번에 몰아 사는 구간이라, 여기서 잡은 팔로워가 그대로 0~36개월 구매 고객으로 이어집니다.

📤 게시물

인스타그램 자동 업로드. 연결되면 민채님 손이 완전히 빠집니다.

⚠️ 아직 계정이 연결되지 않았습니다. 아래 3단계는 계정 소유자 인증이 필요해서 민채님이 한 번만 해주셔야 합니다. 5분이면 끝납니다.

🔌 연결 절차

1
인스타 계정을 프로페셔널(비즈니스)로 전환
설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환. 개인 계정은 API 업로드가 불가능합니다.
2
페이스북 페이지 생성 후 인스타와 연결
Graph API의 필수 조건입니다. 페이지는 비워둬도 되고, 운영하지 않아도 됩니다.
3
계정 아이디 전달 + 액세스 토큰 발급
토큰은 제가 발급 절차를 안내합니다. 비밀번호는 제가 직접 입력하지 않습니다 — 민채님이 입력하시는 화면에서만 진행됩니다.

방식예약발행PC 꺼져도세팅권장
