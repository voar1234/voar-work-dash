🔌 연결 절차

1
인스타 계정을 프로페셔널(비즈니스)로 전환
설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환. 개인 계정은 API 업로드가 불가능합니다.
2
페이스북 페이지 생성 후 인스타와 연결
Graph API의 필수 조건입니다. 페이지는 비워둬도 되고, 운영하지 않아도 됩니다.
3
계정 아이디 전달 + 액세스 토큰 발급
토큰은 제가 발급 절차를 안내합니다. 비밀번호는 제가 직접 입력하지 않습니다 — 민채님이 입력하시는 화면에서만 진행됩니다.
