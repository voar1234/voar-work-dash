📖 사용법 가이드

1. 화면 구성

  • 카테고리 탭 — 상단의 생활가전/육아/계절가전/주방가전 선택. "전체" 선택 시 모든 카테고리 표시
  • 뷰 모드:
    • 📦 제품별 보기: 드롭다운에서 제품 하나 선택해 그 제품의 키워드 확인
    • 📚 카테고리 통합 보기: 선택된 카테고리의 모든 제품 키워드를 한 테이블에 표시 (제품명 칼럼 포함)
  • 키워드 검색: 검색창 입력 시 실시간 필터링
  • 그룹 색상: 🟢 A 메인 / 🟡 B 인접 / ⚪ D 혼재 / 🔴 C 사용금지

2. 새 제품 추가 (사용자 액션 2개)

  1. 제품 설명서 PDF를 화면 어디든 드래그앤드롭 (또는 우측 상단 🆕 버튼)
  2. 모달이 자동으로 열리면 카테고리만 라디오 선택 + 📤 PDF 저장 + 분석 시작 클릭
  3. Claude 채팅창에서 아무 메시지나 한 번만 보내세요 (예: "확인", "ㅇ", "네" — "ㄱㄱ" 안 쳐도 됨)
  4. Claude가 last_upload.json의 pending_analysis 플래그를 보고 자동으로 4단계 분석 시작 + 대시보드 JSON 업데이트
  5. 대시보드 새로고침(F5)으로 결과 확인

⚠️ 주의: 이 기능은 server.py가 실행 중일 때만 작동해요. (단순 정적 서버는 PDF 업로드 안 받음)

3. 설명서 보기

제품 정보 카드의 📄 설명서 보기 버튼 클릭 시 PDF가 새 탭에서 열림 (브라우저에 따라 다운로드될 수 있음)

4. 데이터 구조 (직접 편집)

HTML 파일 안 <script id="productData"> 영역에 JSON 형식으로 누적 저장. 키워드 수동 수정 시 이 부분 편집.
